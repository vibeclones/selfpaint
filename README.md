# selfpaint (Vibeclones mirror)

Hosted copies of the browser (WebAssembly) builds of [SelfPaint](https://github.com/selfbin/selfpaint), by selfbin. The newest version lives at playground.daijro.dev/selfpaint; this repo keeps older versions open-able so the timeline can be explored in a browser. This repo only mirrors upstream release zips; the code is theirs. Upstream license: MIT.

- Latest: `/selfpaint/latest/`
- Specific version: `/selfpaint/v<version>/`
- Version list: `/selfpaint/versions.json`

Each version folder is the unmodified contents of upstream's browser build zip from the matching release. A scheduled workflow mirrors new releases.
